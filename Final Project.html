Analyzing Key Factors of Calorie Burn Efficiency in a Workout

Motivation and Context

Often times, we do our research on calories involving diet, exercise, and lifestyle overall because calories are the energy we need to function throughout the day. We burn calories in order to balance our calorie intake, improve metabolic efficiency, and reduce stress. However, with busy daily routines, finding time for this can prove to be difficult.

In this investigation, I will analyze the demographics and living habits of users in order to investigate any correlations with calorie burn in a workout.

I was pretty active in middle school and high school, but once I entered college and started working, finding time for physical activity grew more difficult. I tried many different types of workout routines and eventually developed one tailored to me I enjoy and fits in my busy school and work schedule. I noticed that when I worked out pretty consistently, I got better sleep and my mood improved, which sparked my interest in the topic.

Main Objective

The data set is designed to help analyze and predict workout efficiency. However because only one workout session for each user was recorded, I decided to analyze what variables are more effective in burning calories during a workout.

This data set is from Adil Shamim from Kaggle and synthetically generated to simulate real-world fitness tracking data. The data mimics information collected from different fitness apps.

Data Limitations

As mentioned earlier, this data is synthetically generated and only represents similar real user data and some relationships between variables may not be fully precise. On top of that, the creater of the data set used Python to create randomly generated numbers in a given range for each variable, without considering real-world characteristics they could have. For example, most people range between a height of 159cm-171cm, which should mean our height variable should have a normal distribution. However, when we take a look at the actual variable height, we see that there are an equal frequency within the range of 150cm and 199cm, which could potentially cause bias.

Another limitation in this data set is the potential of multicollinearity in the data, which can affect the model’s performance.

Data Wrangling

I checked the data set for any missing or NA variables and split the data into a training (75%) and testing set (25%). Before I chose what I was going to analyze, I manipulated the variables in a way I thought was fit for this study and ended up not needing to do this, but felt it was important to include as a part of my data wrangling.

BMI

I converted the height into meters and took the weight and divided by the height (meters) squared to get the user’s BMI. These values were then sorted into:

  • BMI < 18.5, “Underweight”

  • 18.5 < BMI < 24.9, “Normal Weight”

  • 24.9 < BMI, “Overweight”

Mood Change

I converted the categorical variable Mood Before Workout and Mood After Workout into a numerical variable:

  • Happy or Energized= 2

  • Neutral = 1

  • Stressed/Tired or Fatigued= 0

and then took the difference between the values. If the value was positive, mood improved; If the value was negative, mood worsened.

Modeling

I chose to use obtain a LASSO model with the data set because I wanted to see which variables were most significant in burning calories. As a result, I successfully identified that the higher a user’s age, steps taken, sleep hours, daily calories intake, resting heart rate, mood after workout, mood change, gender, and workout type contributed to burning more calories. Also, the lower a user’s height, weight, workout duration and heart rate contributed to burning more calories. Because Calories Burned is a numerical variable, I chose to select the model using a RMSE. RMSE represents how far off I am in calories.

Insights

Despite using LASSO regression for variable selection, no predictors were significantly important under sample splitting. This suggests some multicollinearity within the variables.

In this figure above, we see that the trend has a huge decrease as penalty grows. This suggests that more variables improves performance, but not by much, which further explains our LASSO model.

This figure shows the LASSO coefficient path, each line representing a predictor’s coefficient. We can see that no variables remained dominant as penalty increased. Again suggesting little significance.

Limitations and Future Work

The model is poorly predicting the outcome of our response variable due to the synthetic data. Because of this, the data lacks the complexity and meaningful relationships typically found in actual fitness data. Future improvements could be the use of an actual fitness data set with more features that might reveal stronger relationships. Also maybe using nonlinear methods that can reveal what linear methods missed because LASSO assumes a linear relationship and well as independence.

There are no privacy concerns involving this data set because these numbers were randomly generated, however had we used real data, we would need to consider data privacy and user transparency.
